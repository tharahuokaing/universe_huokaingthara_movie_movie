## 🎯 About the Module / អំពីម៉ូឌុល

**`universe_huokaingthara_movie_movie`** provides an interactive film catalog and screening watchlist for **UNIVERSE HUOKAING THARA Group**. Visitors can filter films by genre, search by title or status in real time, save films to a session watchlist counter, and open full film dossiers in a modal window.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **🔎 Live Search & Genre Filtering:** Filter titles by category (*Cinema, Drama, Thriller & Ghost*) or search keywords, genres, and statuses in real time.
* **🔖 Interactive Watchlist & Counter:** Save or unsave films directly from any card with a live watchlist badge counter.
* **🎞️ Film Dossier Modal:** Inspect each title's genre, production/screening status, and synopsis notes inside a structured modal window.
* **🌐 Dual Language Switcher (Khmer / English):** Instant toggle supporting Khmer-only, English-only, or bilingual display modes.
* **🌙 Dark / Light Cyberpunk Theme:** Styled with the signature **UNIVERSE HUOKAING THARA** holographic scanline aesthetic and adaptive theme switching.

## 🛠️ Tech Stack & Architecture / បច្ចេកវិទ្យាប្រើប្រាស់

- **Frontend Core:** Semantic HTML5, CSS3 (CSS Grid, Flexbox, Custom Properties), Vanilla JavaScript (ES6+)
- **Typography:** Google Fonts (`Kantumruy Pro` for Khmer script, `Poppins` for English UI)
